# Lingua — GitHub Pages

Версия от 1 ноября 2026. Сборка не требуется.

## Публикация
1. Распакуйте архив. Загрузите его содержимое в корень репозитория Faust-R/Translate-video-call- (index.html должен лежать в корне, не внутри дополнительной папки). Не загружайте ZIP как единственный файл.
2. В Settings → Pages выберите Deploy from a branch, ветку main (или вашу основную ветку), папку /(root), затем Save.
3. Откройте адрес сайта, который покажет GitHub Pages. Создавайте новые приглашения на этом адресе. Старые ссылки chatgpt.site не переносятся.

## Использование
Организатор: модель/ключ для титров сверху, ниже модель/ключ для чата. Проверить выполняет тестовый запрос: Live setup без микрофона или перевод слова Hello для текстовых моделей; возможен небольшой расход API. Успешная проверка — доступ в момент проверки, не гарантия будущей квоты. Для чата Gemini пустое поле использует ключ титров. Для DeepSeek Gemini не нужен.
Создайте ссылку и оставьте вкладку открытой. Приглашение действует 15 минут до подключения и рассчитано на одного гостя. Гость начинает на вьетнамском; RU/EN/VT меняют меню и язык перевода. Дополнительный выбор языка перевода независим от меню.
Камеру можно перетаскивать пальцем или мышью; после фокуса работают стрелки клавиатуры. Кнопки в левом верхнем углу видео и чата включают/выключают полный экран, с адаптацией для браузеров без Fullscreen API.
Показываются три последние реплики, оригинал тонкий, перевод жирный. Чат сохраняется в памяти всю текущую сессию. Завершение/перезагрузка очищает чат, титры и открытые ключи. Зашифрованная копия ключей, если сохранена, остаётся в браузере.

## Сохранение ключей
В блоке «Сохранение ключей» введите один или несколько API-ключей и пароль минимум 8 символов, затем «Сохранить». Используются AES-GCM 256 и PBKDF2-SHA256 (600000 итераций), случайные соль и IV. Пароль приложение не сохраняет и не отправляет. При следующем посещении нажмите «Разблокировать» после ввода пароля. Пустые поля при сохранении не удаляют прежние ключи. Новый ключ заменяет прежний после нажатия «Сохранить». Для удаления есть отдельные кнопки.
Забытый пароль восстановить нельзя: удалите сохранённые ключи и введите их заново. Хранилище привязано к браузеру и адресу сайта; очистка данных браузера удаляет его. Используйте HTTPS (GitHub Pages) или localhost. Шифрование защищает сохранённую копию, но не от вредоносного кода на уже разблокированной странице. Не используйте короткий предсказуемый пароль. Гость не получает доступа к этому блоку.

## Ограничения
Чат пока использует соединение видеозвонка: нужны разрешения камеры/микрофона. Оба участника должны оставаться онлайн. Используются PeerJS Cloud и STUN Google; TURN отсутствует, поэтому в некоторых сетях прямое соединение невозможно. Перенос на GitHub не устраняет peer-unavailable, если организатор отключился.
Голосовые модели Gemini зависят от доступа и квоты ключа. Два направления выполняются в браузере организатора. Live Translate генерирует аудио, которое не воспроизводится, но может тарифицироваться.
Ключи не включены в файлы и не отправляются гостю. Приложение не сохраняет историю; сторонние сервисы применяют собственные правила хранения. Не вставляйте ключи в код или GitHub Secrets: их вводят на сайте.

## Проверки
Node.js 20+: node tests/flow.cjs, node tests/chat.cjs, node tests/translation.cjs, node tests/deepseek.cjs, node tests/controls.cjs, node tests/vault.cjs. Тесты API используют заглушки; реальный запрос проверяется кнопкой с вашим ключом.

## Файлы
index.html, style.css — интерфейс; app.js — соединение; translation.js — голос; chat.js — чат; ui.js — языки/полный экран; controls.js — проверки/камера; vault.js — шифрованное хранилище ключей; role.js — гостевой режим; pcm.js — аудио; peerjs.min.js — PeerJS (лицензия в LICENSE.peerjs).
